# StudyTask Manager

A web-based study task management application that helps students organise and track academic responsibilities such as assignments, revision tasks, quizzes and project deadlines in one central place.

## Project Description

StudyTask Manager is built with plain HTML, CSS and JavaScript. It provides a structured, user-friendly interface that allows students to create, update, delete and view study tasks, with input validation and a basic login system to protect user data.

## Features

- Home page with application overview and an image gallery
- Basic login system that restricts access to task management
- Create, update and delete study tasks (with delete confirmation)
- View all tasks in an organised table
- Form validation with clear error messages
- Current date and time display
- Project plan and troubleshooting blog
- Ethics and privacy reflection

## How to Install and Run

1. Download or clone this repository.
2. Open the `html` folder.
3. Double-click `index.html` (or right-click and open with a web browser).
4. No server or additional software is required.

## How to Use

1. Read the application overview on the home page.
2. Use the navigation bar to open the task management page.
3. Log in with the demo account.
4. Create, edit or delete your study tasks.
