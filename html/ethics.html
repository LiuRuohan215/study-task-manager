Ethics and Privacy Reflection

The tasks entered into this app are personal information. A student's deadlines and course work can show what they are studying and how busy they are, so that data should be treated carefully. While building the app, I tried to make ethical and privacy-conscious choices rather than adding them at the end.

How the App Supports Ethical Data Use

  • Only necessary data is collected. The form asks for the title, course, due date, description and notes, which are all needed to manage a task. It does not ask for extra personal details such as a phone number or address.
  • Input validation protects data quality. Empty required fields and invalid past dates are rejected with clear messages, so incorrect or meaningless data is not stored.
  • Data stays on the user's machine. Tasks are kept in the browser and are not sent to any server or shared anywhere else.

How the App Supports Data Privacy

  • Access is restricted by a login. The task page cannot be opened without the correct username and password, so another person using the same computer cannot view the tasks.
  • The password is hidden while typing. The password field displays dots instead of the actual characters.
  • The user controls their data. Any task can be edited or deleted, including the confirmation step before deletion, so nothing has to stay stored longer than the user wants.

Reflection

This project showed me that privacy is part of the design process, not a feature added afterwards. Simple decisions such as limiting the fields in the form, requiring a login and letting the user delete their data all reduce the risk to personal information. Even a small application handling user-generated data has an ethical responsibility to collect less, protect access and keep the user in control.
