About the App

StudyTask Manager is a simple web app for students. It keeps all of your study tasks in one place so you do not miss any due dates.

Before I made this, I wrote tasks on different pieces of paper and sometimes forgot about them. This app shows every task clearly, and you can change or remove a task when it is finished.

Main features:

  • Create a new task with title, course, due date and notes
  • Edit a task when the details change
  • Delete tasks you do not need anymore
  • See all your tasks in a table
